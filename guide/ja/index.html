SWINGLOG / IPHONE + APPLE WATCH

SwingLog 詳しい使い方

Apple Watchで練習を記録し、ラウンド中の距離とスコアを管理して、iPhoneで振り返るためのガイドです。バージョン1.0・ビルド23の最新開発実装を2026年10月24日に確認しました。配布中のTestFlight・App Store版と一部機能が異なる場合があります。例の数値は説明用です。端末・言語・権限によって表示は異なります。

一致する項目がありません。

はじめに

  1. ペアリング済みのiPhoneとApple WatchにSwingLogをインストールし、両方のアプリを一度開きます。iOS 17以降、watchOS 10以降が必要です。
  2. iPhoneの初回ガイドを読みます。最後のドライバーと7番アイアンの飛距離入力は任意です。後から 設定 → クラブ管理 で入力・修正できます。
  3. 設定で言語、距離単位（m/yd）、右打ち・左打ちを確認します。装着する腕とDigital Crownの向きは、標準ではWatchのシステム設定に従います。実際の装着状態を確認し、必要な場合だけアプリで上書きします。
  4. Watchの 練習モード を開き、案内に従って3回スイングしてキャリブレーションします。ラウンド前にはコースも準備します。

必要な設定とコースが転送され、調整済みであれば、WatchはiPhoneを常に操作しなくても活動できます。記録の転送は接続を待つことがあります。オンラインガイド、コースのダウンロード、購入確認、iCloud同期にはネット接続が必要になる場合があります。

Watchの最初の画面で 練習モード / ラウンドモード を選びます。練習はスイング・テンポ・活動終了のページです。ラウンドは中央がメイン、左のページがハザード、右がスコアです。左右スワイプでページを移動し、長い画面はDigital Crownでスクロールします。

iPhone上部のWatch表示は、その時点で直接通信できる状態を示します。待機中は必ずしも異常ではなく、Watchアプリが閉じている場合にも表示されます。接続表示だけで全記録の転送完了を意味するわけではありません。

練習：調整とスイング回数

  1. Watchで 練習モード を開始します。
  2. 調整が必要な場合は開始し、普段練習する大きさのスイングを3回行います。途中でキャンセルできます。
  3. スイング画面のクラブを選び、開始を押します。検出されたスイングが活動中の回数と今日の回数に反映されます。
  4. 今日の回数/目標と進捗バーを確認します。iPhoneの スイング → 目標変更 で変更した目標はWatchへ送られます。
  5. 停止で検出を止め、再び開始できます。再調整は検出を停止してから行います。
  6. 練習を終えるときは活動終了ページで終了し、サマリーを確認します。テンポ練習の停止と活動全体の終了は別です。

手首の動きによる検出のため、パットや小さなアプローチをすべて数える機能ではありません。検出回数はボールを打った回数やスコアと一致しません。検出漏れ・過検出は装着方向と再調整を先に確認し、その後に感度を調整します。現在の範囲は70–130%で、低いほど敏感、高いほど慎重な検出になります。

Proの 設定 → スイング強度サウンド は、調整時の動きと比べた強度を音で知らせます。クラブヘッド速度や実際の飛距離を測定する機能ではありません。

iPhoneのスイング画面でカレンダーの日付を選ぶと、その日の記録を確認できます。推移では回数と目標を比較します。言語とm/ydは設定で変更できます。単位変更は表示を変えるだけで、保存された実際の距離は変わりません。

iPhoneのライブ練習レポート

Pro未加入でもモーションログ保存がオフでも使えます。iPhoneアプリを前面で開き、ペアリングWatchで練習モードを開始します。両端末が即時通信できるとレポートが自動表示され、検出スイングごとに更新します。測定テンポ、バックスイング・ダウンスイング時間、加速度・回転速度・手首回転角の統合グラフと重力グラフを表示します。

閉じると同じ練習実行中には自動で再表示しません。スイング → 練習分析を表示から再表示するか、Watchの検出を停止・再開して新しい実行を開始します。太陽アイコンはiPhoneの画面点灯維持を切り替え、オフなら通常の画面ロックを使います。

ログ保存がオフなら一時データです。元のサンプルはメモリで処理し、次のスイングで前の表示を置換し、閉じるかバックグラウンドへ移ると破棄します。練習終了や切断後は最後の完了表示が残る場合があります。再接続後は新しいスイングを待ちます。ログ履歴・iCloud・バックアップには保存しません。Proのログ保存と明示的な星付き保持は別の経路です。Watchの測定テンポ・星機能とラウンドモードは引き続きPro機能です。

練習：テンポと振動

iPhoneの テンポ でクラブ種類ごとのバックスイング・ダウンスイング時間、繰り返し間隔、振動テーマを設定します。Watchのテンポ画面で種類を選び開始すると、設定したリズムを繰り返します。種類を変える前に停止してください。ProのiPhone音声練習はWatchなしでも動作し、Watch振動プレビューとは別の機能です。

基本機能ではアイアンのテンポを使えます。Proではドライバー・ウェッジ・パターやレベル別プリセットなども利用できます。パターのリズム案内は、パットの自動検出・記録を意味しません。 時間を手動で変更すると、プリセットの選択表示が外れる場合があります。

測定されたテンポと練習用の設定時間は別です。測定テンポは バックスイング時間 ÷ ダウンスイング時間。0.90秒と0.30秒なら3.0:1です。フルスイングでよく使われる約3:1は目安であり、比率だけで良し悪しを決めるものではありません。

モーション記録と打球音

iPhoneの スイング → スイングモーション分析 にPro用の設定があります。

  • 打球音によるインパクト推定： モーションログ記録とは独立してオンにできます。Watchのテンポ計算を音で補強できますが、すべての打球を確定するセンサーではありません。
  • スイングモーション記録： 練習の詳細センサーデータを保存します。オフでも既存のモーションログは閲覧できます。
  • 高速サンプリング： モーション記録をオンにしたとき、詳細設定に表示されます。対応Watchで追加データを収集しますが、実際の収集率は端末によって異なります。基本検出は50Hzです。容量や転送時間が増える場合があります。

記録をオフ・オンしても高速サンプリングの設定値と独立した打球音設定は維持されます。Watchタイトル横の記録・速度計・波形アイコンは設定状態です。測定テンポ横の 音による補強 / モーションのみ のアイコンは、そのスイングで実際に使った計算根拠です。波形アイコンがオンでも、毎回音が採用されたとは限りません。

ラウンドでは練習の記録設定と別に自動記録を行い、高速設定に関係なく50Hzで動作します。打球音推定はラウンド中に自動で有効になります。省電力モードでは必要な時間帯だけマイクを使うため、音の根拠がないスイングも生じます。

開発用アプローチ収集

Watchの 練習モード → 活動終了ページ → アプローチ収集から開きます。活動を終了する必要はありません。収集画面を開くと通常のスイング検出とテンポ案内を停止し、閉じると以前の実行状態に戻します。XcodeとTestFlightの両方で利用できます。

クラブ、動作（実際の打球・素振り・ワッグル・歩行・クラブの出し入れ・その他）、意図した大きさを選びます。打球音の特徴収集は任意です。収集開始 → 3秒構える → 動作を1回 → 1秒静止 → 収集終了の順に操作します。モーション記録や高頻度設定に関係なく、50Hzの全サンプルを最大20秒収集します。上限で自動終了した後も、確認して手動保存する必要があります。アプリの強制終了前に保存してください。

情報を確認・修正して 収集データを保存します。検出できなかった動作も保存し、通常のスイング回数、星付き基準スイング、コーチングには含めません。既存検出器の候補と判定は比較用に保持します。準備やボタン操作も生データに含まれるため、分析では両端を区別してください。マイク入力や音の候補は実際の打球を保証しません。音声は保存しません。

転送後、iPhoneの モーションログ → フィルタ → 認識結果 → 手動収集で確認できます。詳細の 生データを書き出すで全サンプル・収集情報・検出結果・音の候補をJSONとして書き出せます。転送失敗時はWatchに原本を保持し、再接続時に再試行します。

収集結果には 小さなスイングの観察 が別に表示されます。構え・逆方向の回転・動作のつながりを評価し、候補区間と除外理由を確認できます。既存の手動収集記録もiPhone詳細で現在の観察器により再評価します。候補はスイングやインパクトの確定判定ではなく、回数・テンポ・距離測定に反映しません。意図的なトップでの長い静止も除外されることがある実験段階です。アプローチ収集記録の評価であり、通常の練習・ラウンド中の常時収集ではありません。

星マークと自分の基準

ProではWatchの最新スイングに星を付けられます。輪郭だけの星は未選択、塗りつぶした星は選択済みです。練習のモーション記録がオフでも、星を付けたスイングは保存してiPhoneへ送ります。次のスイングで対象が変わる前に付けると便利です。

iPhoneのログ一覧にも星を表示し、詳細のサマリーで星やクラブを変更できます。星付きスイングとの比較では、同じクラブの認識済み・星付きスイングを使い、現在の記録自身を除外します。各指標に有効な基準データが最低5件必要です。満足したスイングを10–20件ほど集めると、基準の安定性も確認しやすくなります。

時間・テンポは中央値とばらつき、前腕方向は記録開始姿勢からの相対回転を比較します。方向比較には利き手・装着腕・クラウン方向が同じ記録を使用します。データ不足や大きなばらつきでは比較不可・不安定と表示されます。自分の再現性の指標であり、理想的な姿勢、クラブフェース角、カッピングやスクーピングを判定するものではありません。

ラウンド前：クラブとコース

  1. 設定 → クラブ管理 で使用クラブを表示し、名前と基準距離を確認します。クラブをタップして編集します。
  2. ドライバーと7番アイアンの距離から他の標準クラブを推定できます。両方が正の数で、ドライバーが最低10m長い必要があります。推定は出発点です。他のクラブで手動修正した距離は再推定しても維持します。パターとOtherは対象外です。
  3. 変更をまとめてクラブ一覧全体を転送します。下部で状態を確認し、手動同期もできます。標準クラブは非表示にでき、Proでは追加クラブと並べ替えも利用できます。
  4. 設定 → ラウンドモード → コース管理 で1コースを選び、Apple Watchへ送信します。プレー前にWatchでコース名を確認します。Watchは転送された1コースを使用します。

アプリの + で作るのは基準座標中心のLiteコースです。グリーン境界・ティー区域・ハザード・Parを含むコースは SwingLog Course でダウンロード、作成、共有できます。編集には デスクトップのブラウザ を推奨します。取得したJSONをラウンド設定のコース読み込みから取り込みます。

ホール番号とグリーン基準座標が基本情報で、境界・ハザード・ティー・Parは任意です。情報がない項目は表示されない場合があります。大きな距離は保存されたグリーン基準点までであり、その日の実際のピン位置とは異なる場合があります。

ラウンド開始とメイン画面

ラウンドモードは Pro 機能です。Watchで選び、コースを確認して開始ホールを1–18から選択し、ラウンド開始を押します。ショットガンスタートにも対応します。未完了ラウンドがあれば再開できます。

メインにはホール番号、任意のPar、大きなグリーン基準距離、前/後距離、推奨または手動選択クラブを表示します。ホールをタップして直接変更できます。推奨クラブは残距離と登録した基準距離に基づき、風・傾斜・ライ・障害物をすべて判断するものではありません。

自分のショット測定を始めると次のショットの自動推奨に戻ります。そのホールで測定中または保存済みの自分のショットがあれば、自動推奨からドライバーを除外します。手動ならドライバーも選べます。次のクラブを手動選択した場合はそれを優先します。測定中ショットのクラブと次のショット用の選択クラブは別の値です。

主要画面は利用可能な高さに合わせて配置します。小さい画面ではクラブ・星・テンポを一列にまとめ、テンポをタップすると ショット詳細 でバックスイングとダウンスイングの時間を確認できます。状態表示から測定対象の切り替え、自動保存の取り消しや関連案内を開けます。大きな文字などで収まらない場合はスクロールできます。

GPSと距離の準備状態

メイン左上のGPSアイコンを押すと詳細を表示します。緑は準備完了、オレンジ系は受信・精度向上・新しい位置が必要な状態、赤は権限や位置利用の問題です。システム時計付近の固定ツールバーにあるため本文のスクロールでも動きません。

グリーン距離の表示と正確なショット測定の条件は別です。距離が出ていても開始・保存が無効の場合があります。ショット測定では基本的に 5秒以内の位置と10m以内の水平精度 が必要です。一時的に受信が不安定なときは最後の有効なグリーン距離を保持することがあり、数値の表示は最新位置の保証ではありません。

開けた場所で少し待ちます。スイング時の出発位置を取得できなかった場合、後で歩いた場所を代わりに使いません。アプリを強制終了・再起動しても進行中測定のGPS出発点は復元されません。

自分のショット距離測定

  1. 打つ前にクラブを確認します。Watchがスイングとその時刻に対応するGPSを取得する必要があります。
  2. ショット距離測定を押します。歩いてから押しても出発点はスイング位置です。現在のホールの最新の有効スイングで、距離未保存なら別途の経過時間制限はありません。
  3. ボールに着いたら 距離を保存します。2点間の水平距離で、キャリーだけでなくランを含む場合があります。飛行軌道や歩いた道のりの長さではありません。
  4. 誤って始めたら キャンセルします。保存済みのスイングを重複して測定開始することはできません。

測定中は そのショットのクラブ・距離 を表示します。上の推奨クラブは次のショット用で、変わっても測定中の出発点やクラブは変わりません。星は良かったスイングの印であり、距離保存の代わりではありません。

自分のショット測定を続けたままグリーンに近づくと、システムの通知音・振動と保存案内でお知らせします。グリーン形状があれば境界から5m以内または内部、なければ基準座標から20m以内で、正確なGPSが3秒以上続くことが条件です。ショット直後15秒間とスイング中は通知せず、測定ごとに一度だけ通知します。通知音・振動はWatchの設定に従います。距離を保存ボタンが強調されたら、ボールの位置で保存してください。接近だけで自動保存することはなく、自由測定は対象外です。

直前ショットのクラブ修正

3Wが選択されたまま7Iで打った場合、メインのクラブボタンから 直前ショットのクラブ修正 を選びます。対象の時刻とクラブを確認して7Iに変更します。次のショットのクラブ選択は次回だけに適用する別の操作です。

Watchでの修正は、同じスイングのラウンド関連情報、モーションログ、測定中または保存済み距離のクラブに反映されます。GPS出発点、記録時刻、距離、センサーデータは維持します。選択画面中に新しいスイングが発生すると対象が無効になる場合があるため、開き直します。iPhoneのモーションログ・距離詳細の個別編集は、このWatch側の一括修正とは区別してください。

自動測定と次のショット

iPhoneの 設定 → ラウンドモード → ショット距離の自動測定、またはWatchのスコア設定で有効にします。初期値はオフで両端末に同期します。以降のスイングに正確なGPSがあると仮測定を開始します。オフにしても測定中の距離は保持し、新規自動測定を停止します。

手動開始した測定にも次のスイングによる自動終了が適用されます。同じホールで30秒以上経過し、距離が25mと両端のGPS誤差合計の2倍を超え、両端の精度が10m以内、距離が500m以下であることが条件です。

根拠処理
時間・移動・GPSが適合し、強く時刻の合う打球音あり前の距離を保存し、自動測定がオンなら同じ位置で新しいショットを測定します。
時間・移動・GPSが適合し、打球音が弱い・ない確認画面なしで同様に保存・接続します。iPhoneで確認するまでクラブ距離統計から除外します。
時間・移動・GPSが不足測定を続けます。目的の位置で保存・取消してください。短いアプローチは手動保存が必要な場合があります。

メイン画面は測定中のクラブと現在の距離を表示します。20秒間の任意の取り消し案内は次のショット処理を妨げません。後から歩いた位置で欠落したスイング位置を代用しません。入力したスコアは変更しません。

ショット地図と修正

初めて新規ラウンドを開始するとWatchでショット位置の保存を選択できます。以降の保存はラウンド設定で変更できます。連続移動経路は記録しません。位置は個人のiCloudとラウンドバックアップに含まれます。

iPhoneの ラウンド記録 → スコアカード → ショット地図と編集 を開きます。同一ホールの連続した距離記録を選び、最初の始点から最後の終点まで統合します。最初のクラブとモーションを使用し、保存終点がなければ統合できません。左スワイプでラウンドと距離統計から除外します。直前の編集を戻すと統計状態も復元し、スコアと元のログは保持します。

モーション・GPSのみで保存した距離は統計から除外されます。必要なら 距離を確認して統計に含める を選びます。GPS等のシステム条件に合わない距離は強制的に含められません。保存位置の削除は編集履歴の位置も消去し、距離・ログ・スコアは保持します。削除は後にiCloudとWatchへ反映し、書き出したコピーは別途管理してください。

ラウンド中の素振り

短い間隔のスイングは一つの場所での候補として一時保持します。20秒以内に繰り返され、移動の確かな根拠がなければ、保護されていない前の候補を新しい候補で置き換える場合があります。GPSでその場所から離れたことを確認して最後の候補を残します。

星、明示的な測定操作、クラブ修正などで保護されたスイングは維持します。間隔が長い場合や根拠が曖昧な場合は複数を残すことがあります。実打と素振りの完全な分類ではありません。モーションログの保存数と独立した検出カウンターは異なる場合があります。スコアは必ず自分で確認してください。

ハザードと自由距離測定

メインから右スワイプして左のハザードページを開きます。コースデータにあるバンカー・ハザード境界までの距離範囲を表示します。データにない障害物は表示できません。

下部の 自由距離測定 → 距離測定開始 は同伴者のショットなど任意の2地点を測る機能です。出発点で開始し、到着点で 測定終了します。結果は閉じるか再測定するまで保持されます。キャンセルは進行中の測定を取り消します。

自由測定はショット、クラブ関連情報、ラウンド記録を保存しません。自分のショット測定と同時に動作し、一方を終了しても他方は続きます。どちらもWatch着用者の現在位置を終点に使うので、それぞれ目的地で終了してください。

スコア・ホール移動・休憩・終了

メインから左スワイプして右のスコアページを開きます。打数はそのホールのパットを含む総打数です。パット数は任意で、打数を超えられません。罰打専用欄はないため最終打数に含めます。同伴者用の別スコアカードには対応していません。

値を変更すると保存します。初期値はそのホールのPar（不明なら4）と最大2パットで、検出数に2を加えたものではありません。画面を開くだけでは初期値を確定しません。次のホール：N番で表示中のスコアを確定して進みます。ショットガン順序では18から1へ進み、開始ホールを繰り返す前に終了します。

自分の測定中に次のホールを押すと 距離を保存して次のホール / 測定を取り消して次のホール / 戻る が出ます。保存はGPSを待つ場合があります。ティー区域と前ホールの保存済みスコアがあれば次のティー到着時に移動を提案できますが、GPSだけで強制変更しません。

休憩には ラウンド → 一時停止 を使います。モーション・位置・マイクなどを停止し、再開で起動します。自分の測定と自由測定が進行中なら先に終了・キャンセルします。休憩もラウンド開始から終了までの所要時間に含まれます。

終了で 保存して終了 / 保存せずに終了 / ラウンドを続ける を選びます。保存は終了時刻とラウンド・スコアをiPhoneへ送ります。保存しない場合はラウンド・スコアだけを破棄し、残っているスイングや保存済み距離は維持します。続行は活動へ戻ります。終了確定で未完了の測定はキャンセルされるため必要な距離は先に保存します。

省電力

iPhoneのラウンド設定とWatchスコア画面上部の歯車ボタン内の 省電力モード は同じ設定です。標準のラウンドでも50Hzとまとめた記録転送を使います。省電力をオンにすると移動・静止・手首の動きから必要な時間帯にマイクを限定し、測定していない移動中はGPS要求精度を下げます。自分の測定・自由測定中は高い精度を維持します。

検出は続きますが、マイク停止・再開時に音の根拠が得られないことがあります。その場合はモーションによるテンポや手動距離保存を使えます。休憩には一時停止も利用します。持続時間は機種、バッテリー状態、ラウンド時間、GPS環境で変わり、18ホール完走を保証しません。

モーションログの一覧と詳細

iPhoneの スイング → モーションログを見る を開きます。日付ごとに記録開始時刻（秒まで）、クラブ、星が表示されます。期間（全件・今日・7日・30日）、クラブ、星、認識結果を組み合わせて絞り込みます。編集時もフィルターを維持し、全選択・日付別全選択で削除できます。1件の削除は左スワイプです。

詳細には関連する測定距離、時刻、クラブ・星、最大加速度・回転速度、サンプル数、テンポ、個人比較を表示します。継続時間は記録区間の長さで、必ずしもバックスイングとダウンスイングの合計ではなく、長いほど良いという意味でもありません。前後の動きを含む場合があります。

テイクアウェイ・トップ・インパクトはセンサー根拠からの推定です。バックスイングはトップ−テイクアウェイ、ダウンスイングはインパクト−トップで計算します。区間不足では表示できません。次の練習ガイドは記録品質と判定に基づくルール型の案内であり、生成AIの回答ではありません。

グラフと生データの出力

グラフをまとめて表示では加速度・回転速度・手首回転角を、それぞれの最大値を100%として重ねます。タイミングと形を比べるもので、物理量や単位が同じという意味ではありません。オフでは加速度 → 回転速度 → 手首回転角を別々に表示し、重力はその後に独立表示します。

  • 加速度（g）：Watch・手首の加速度の大きさで、ボールの加速度ではありません。
  • 回転速度（rad/s）：Watchの角速度の大きさで、ヘッドスピードやボール速度ではありません。
  • 手首回転角（°）：Watchの相対姿勢で、手首関節だけの曲がりやフェース角ではありません。
  • 重力X/Y/Z：Watch座標での重力成分で、姿勢変化を見るものです。

横軸は記録内の経過時間です。結合グラフは主要動作区間、個別グラフは記録区間を表示します。推定区間線と音候補の表示を一緒に確認し、音候補の存在とテンポに採用された根拠は区別します。

生データ書き出し（JSON）は保存された全サンプルとメタデータを共有します。OSが算出した姿勢・重力・クォータニオンやアプリの計算値も含むため、未処理の電気信号ではありません。音声録音は含みません。高速記録は容量・転送時間が増える場合があります。

AI分析の依頼

アプリは分析用テキストを端末内で作成し、AI回答の生成やサービスへの自動送信はしません。共有シート・コピーから外部AIを選びます。共有後にはそのサービスのデータ方針が適用されます。

  1. 1スイング： 詳細から指標と最大150点の時系列を共有します。主要時刻・ピークを優先し、完全なJSONとは異なります。
  2. パターン： 一覧のAI分析から認識済み3–10件を選択します。5件以上が推奨です。同じクラブ・似た条件だと比較しやすくなります。全件の要約と代表・差の大きい一部の波形を使います。
  3. ラウンド： スコアカードから文書を確認して共有します。そのラウンドに関連するスイング・距離・各ホールスコア・任意のパットのみを使い、同日の別練習は自動で含めません。

数値の観察と根拠の品質、欠損ショットを合わせて判断します。AIが球筋、フェース角、体の姿勢を断定した場合は、Watchデータだけで裏付けられるか確認してください。

iPhoneのラウンド・距離履歴

ラウンド/距離 → ラウンド記録には総件数と月別グループがあります。全件/年フィルターは再起動後も維持します。スコアカードには開始・終了時刻（分まで）、休憩を含む所要時間、OUT/IN表、ホール別スイング・距離・星・ログリンクがあります。未入力ホールを0打と扱わないでください。

ラウンドは左スワイプまたは編集・全選択で削除します。ラウンド削除で関連スイング・距離まで削除されるわけではありません。それぞれの一覧で管理します。

距離タブには最新 25件 と全記録への入口があります。統計の30日・90日・全期間はクラブ集計に適用し、最新一覧は独立して25件を表示します。全履歴では期間・任意の日付・クラブ・統計対象・並び順を選び、日別表示します。追加表示が可能です。編集時の全選択は読込済み行だけでなく フィルターに一致する全件 を対象とします。

統計は対象記録の平均・中央値・最長・件数です。出発/到着精度が10m超、距離20m未満・500m超は自動除外します。有効な記録は詳細から対象外・再対象にできますが、システム無効記録を強制的に含めることはできません。除外と削除は別です。

iPhoneだけで距離測定

ラウンド/距離の簡易測定で使用クラブを選び開始します。GPS待機中は出発地点に留まり、到着地点で終了し、結果を確認して保存・再測定します。測定と結果確認は基本機能、記録保存はProです。

iPhoneのGPSを使い、Watchの自分の測定・自由測定とは独立します。タブ移動では測定を維持しますが、強制終了後の復元は保証しません。記録時刻は開始ボタンの時刻で、保存時刻とは別です。Watchのスイング関連距離は、そのスイングの記録開始時刻を使用します。

同期・バックアップ・削除

Watchでローカル保存してからiPhoneへ転送します。省電力の一括転送や候補処理で遅れることがあります。ラウンド・スコアカードは終了して保存した後に送ります。接続復帰時に保留転送を再試行します。

設定 → iCloudバックアップでアカウント・同期状態と最終成功時刻を確認します。iPhoneのストアは全モーションログを含め個人iCloudに同期します。削除も同期するため、過去の状態を残す別ファイルのバックアップとは異なります。購入権限はiCloud記録ではなくApp Storeで確認します。

ProのJSON データをエクスポート / データをインポートは記録と対応設定を保存・復元します。IDと更新時刻で統合し、コースだけの出力とは別です。高速・打球音・自動測定・省電力など端末別設定や権限・購読まで全部を復元するわけではないため、復元後に確認してください。書き出したファイルはご自身で管理します。

全データ削除はiPhoneを初期化し、Watchにも削除を要求します。接続・iCloudへの反映を確認してください。別途保存したファイルは消さず、購読も解約しません。追加クラブの削除は関連距離記録も削除する場合があるため、確認画面の件数を読みます。

基本機能は今日の回数・目標、iPhoneライブ練習レポート、アイアンテンポ、iPhone距離測定・結果確認などです。Proではラウンド、モーションログ・Watch上の測定テンポ・星比較、カレンダー・推移、距離記録・統計、追加テンポ、クラブ追加・並べ替え、ファイルバックアップなどを利用できます。各画面のロック表示を確認します。
